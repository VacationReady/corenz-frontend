COMMIT 2: Dependency Hygiene
----------------------------------------

Removed unused packages:
- @auth/prisma-adapter (duplicate, using @next-auth/prisma-adapter)
- @hello-pangea/dnd, @reactflow/* (unused flow/drag libraries)
- @vercel/kv (unused KV client)
- axios (replaced by native fetch)
- bcrypt (duplicate, kept bcryptjs)
- bufferutil, utf-8-validate (unused WebSocket utilities)
- debug, supports-color (unused utilities)
- file-saver, jsonwebtoken, react-countup, react-native-web
- @tiptap/extension-mention (unused rich text extension)

Added missing dependencies:
- server-only (enforce server-only modules)
- vitest, jsdom, @testing-library/react (testing infrastructure)
- dotenv (script environment loading)
- @fullcalendar/list, @fullcalendar/core (calendar dependencies)

Result: Cleaner dependency tree, reduced bundle size, improved security posture.

COMMIT 3: TypeScript Safety
----------------------------------------

feat(typescript): Tighten compiler options for better type safety

Enable stricter TypeScript flags:
- allowJs: false (TypeScript-only codebase)
- noUncheckedIndexedAccess: true
- noImplicitOverride: true
- noFallthroughCasesInSwitch: true
- noImplicitReturns: true
- noPropertyAccessFromIndexSignature: true

Explicitly exclude .js files:
- scripts/**/*.js
- prisma/seed.js
- mobile/

Deferred for gradual migration (commented out):
- exactOptionalPropertyTypes
- noUnusedLocals
- noUnusedParameters

Files changed:
- tsconfig.json
