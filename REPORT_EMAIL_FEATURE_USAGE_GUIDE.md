# Report Email Feature - Quick Start Guide

## 🚀 Getting Started

### Step 1: Access Your Reports
Navigate to **Reports** from the main menu to see all your saved reports.

### Step 2: Choose Your Action

#### Option A: Send from Report Preview
1. Click **View** on any saved report
2. Look for the new **"Send Report"** button (with mail icon)
3. Click to open the send modal

#### Option B: View History from Reports List
1. Click **History** button (with clock icon) next to any report
2. See complete send history without opening the report

---

## 📧 Sending a Report

### Recipients Selection

**Departments:**
- See all departments in your company
- Check individual departments
- Use "Select All" to quickly select everything
- Selected count shown at bottom

**Job Roles:**
- See all job roles in your company
- Check individual roles
- Use "Select All" for quick selection
- Selected count shown at bottom

**Requirements:**
- Must select at least one department OR one job role
- Can select both for broader reach
- System automatically handles duplicates

---

### Format Selection

Choose between two options:

#### 📄 PDF
- Clean, professional layout
- Ready to print
- Ideal for presentations
- Fixed formatting

#### 📊 Excel (CSV)
- Editable spreadsheet format
- Import into Excel/Google Sheets
- Ideal for further analysis
- Flexible data manipulation

---

### Email Customization

#### Subject Line (Required)
- Default: "Report: [Report Name]"
- Fully customizable
- Clear and descriptive recommended

#### Message Body (Optional)
- Add context or instructions
- Use `{firstName}` for personalization
  - Example: "Hi {firstName}, please review..."
  - Automatically replaced with recipient's first name
- Supports line breaks for formatting

---

## 📊 Viewing Send History

### Access Points

1. **From Report Preview**: Click "View Send History" button
2. **From Reports List**: Click "History" button on any report

### History Information

Each send entry shows:
- **Format**: PDF or Excel icon
- **Recipient Count**: Number of people who received it
- **Sent By**: Name of person who sent it
- **Date & Time**: When it was sent

### Expanded Details

Click **"Details"** on any entry to see:

#### Email Content
- Subject line used
- Message body (if provided)

#### Recipients Breakdown
- **Departments**: List of all departments included
- **Job Roles**: List of all job roles included
- **Individual Emails**: Every recipient's email address

## 💡 Tips & Best Practices

### Recipient Selection
- ✅ Use departments for org-wide reports
- ✅ Use job roles for function-specific reports
- ✅ Combine both for targeted sends
- ⚠️ Remember: Users in multiple departments/roles only receive one email

### Email Content
- ✅ Keep subject lines clear and descriptive
- ✅ Use personalization for better engagement
- ✅ Add context in message body when needed
- ✅ Test with yourself first

### Format Choice
- **Use PDF when:**
  - Sending to executives
  - Report needs to be printed
  - Fixed formatting is important
  - Professional presentation matters

- **Use Excel when:**
  - Recipients need to analyze data
  - Further calculations needed
  - Data needs to be manipulated
  - Import to other systems required

## 🔍 Example Workflows

3. Select "All Departments"

5. Subject: "Monthly Headcount Report - October 2025"

## ❓ Troubleshooting

### "No recipients found" error
- **Cause**: Selected departments/roles have no active users
- **Solution**: Check user assignments or select different recipients

### Send button disabled
- **Cause**: Missing required fields
- **Solution**: Ensure you have:
  - At least one department OR job role selected
  - Subject line filled in

### Empty send history
- **Status**: Normal if report never sent
- **Action**: Send the report to create history
